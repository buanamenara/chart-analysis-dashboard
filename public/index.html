      Expert Advisor MT5

      EA ScalpRR2 siap digunakan untuk XAUUSDm (Exness) dan BTCUSD (Vantage):

      • Default: sinyal saja. EA mengirim notifikasi ke MT5 di HP dan menggambar level Entry/SL/TP di chart. Tidak ada order otomatis kecuali InpAutoTrade=true.
      • TP & SL dalam dolar (bukan pip), RR 1:2 ($10 target / $5 risiko default).
      • 2 setup: Trend pullback (EMA + RSI) atau Liquidity sweep (SMC).
      • Rem harian: batas rugi, entry maksimum, kalah beruntun.
      • Filter sesi London + New York (UTC 07:00–17:00).

      Spread Exness (XAUUSDm Standard)

      Dari screenshot user (4 Nov 2026, sesi New York): bid 4048.435, ask 4048.675 → spread ~$0.24 pada 0.01 lot.

      EA otomatis lewati sinyal bila spread > InpMaxSpreadUSD ($0.50 default).

      Catatan Penting

      Win rate 85% pada RR 1:2 tidak realistis berdasarkan penelitian trading sistematis. Target yang layak adalah win rate 38%+ (break-even 33% untuk RR 1:2) yang bertahan di data uji.

      Uji di akun DEMO minimal 1 minggu sebelum memakai uang sungguhan. Strategy Tester MT5 memakai data broker (bisa berbeda dari Binance).

      Cara Cepat: Kompilasi EA
      1. Buka MT5 desktop → tekan F4 (MetaEditor).
      2. Klik File → New → Expert Advisor (template).
      3. Wizard: nama ScalpRR2, klik Next sampai Finish.
      4. Hapus semua kode template, lalu copy-paste isi mt5/ScalpRR2.mq5.
      5. Klik Compile (F7) → harus 0 error.
      6. Restart MT5 atau Refresh Navigator → EA muncul di Expert Advisors.
      7. Drag EA ke chart XAUUSD/BTCUSD → atur parameter → OK.
      8. Pastikan Algo Trading aktif (ikon hijau di toolbar).

      Panduan lengkap ada di mt5/INSTALL.md.
